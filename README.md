# کۆدکەر · Kodker

**پڕۆگرامینگ بە زمانی کوردی**

زمانێکی پڕۆگرامینگی کراوە (open-source) بە سینتاکسی کوردی (سۆرانی) کە دەگۆڕدرێت بۆ JavaScript.
وێبگەڕەکەت بکەرەوە، کۆد بنووسە و جێبەجێی بکە، بێ دابەزاندن.

[**🚀 Playground**](https://hamaleo.github.io/kodker/) · [**🎓 فێرکاری**](https://hamaleo.github.io/kodker/tutorial.html) · [نموونەکان](examples) · [ڕێنمایی](#-ڕێنمایی-خێرا)

*A Kurdish (Sorani) programming language that compiles to JavaScript, with a zero-install web playground.*

```
// یەکەم پڕۆگرامم بە کوردی
کار فیبۆ(ن) {
  ئەگەر ن < ٢ { گەڕێنەوە ن }
  گەڕێنەوە فیبۆ(ن - ١) + فیبۆ(ن - ٢)
}

بۆ i لە ٠ تا ١٠ {
  چاپ("فیبۆ(" + i + ") =", فیبۆ(i))
}
```

## ✨ تایبەتمەندییەکان

- **سینتاکسی کوردی**: `ئەگەر`، `بۆ`، `هەتا`، `کار`، `چاپ`، `پۆل` ...
- **ژمارەی کوردی/عەرەبی**: `٠١٢٣` و `0123` هەردووکیان کار دەکەن، هەروەها فاریزەی کوردی `،`
- **Playground لە وێبگەڕدا**: بێ دابەزاندن، **هایلایتکردنی سینتاکس**، بەستەری هاوبەشکردن، نموونە ئامادەکراوەکان
- **تەواوکردنی خۆکار**: کاتێک دەنووسیت، پێشنیاری وشە و فەنکشن و میتۆد و ناوی گۆڕاوەکانت دەردەکەوێت (`↑` `↓` بۆ هەڵبژاردن، `Enter` یان `Tab` بۆ قبوڵکردن، `Esc` بۆ داخستن). وشەکانی `ئەگەر`، `بۆ`، `کار`، `پۆل` ... قاڵبی تەواو دەنووسن
- **🎨 کێشانی گرافیک**: کانڤاس (`بازنە`، `لاکێش`، `ئەستێرە`، `خۆر` ☀ ...)، قەڵەمی کیسە (Turtle) و ئەنیمەیشن بە `فریم()`. ئاڵای کوردستان بە ٨ دێڕ دەکێشرێت!
- **🎓 فێرکاری ئەنتەراکتیڤ**: **١٧٠ وانە لە ٩ بەشدا** (بنەڕەتەکان، بڕیار و دووبارەکردنەوە، کار/لیست/ئۆبجێکت/پۆل، ئەلگۆریتم، مەشقەکان، **شیکاری داتا**، کێشان، پڕۆژەکان). بابەتەکان: گۆڕاو، بەراوردکردن، `ئەگەر`/`هەڵبژێرە`/ئەگەری کورت، بازنەکان، کار و Recursion و Callback و Closure و Scope، لیست و ئیندێکس و خشتە و ستاک/ڕیز، ئۆبجێکت، پۆل و میرات، هەڵە، **دۆزینەوەی هەڵە (Debugging)**، کێشان، Turtle، سینۆس/کۆسینۆس، هێڵکاری، ئەنیمەیشن، ، ١٧ مەشقی کلاسیک (ساڵی بیسەکست، ئارمسترۆنگ، قەیسەر، Project Euler...) ، شیکاری داتا (CSV، Group By، Top N، هیستۆگرام) و ١٦ پڕۆژە. هەر وانەیەک ئەرک، ئاماژە، وەڵام، پشکنینی خۆکار و «🔑 بیرت بێت»ی هەیە. پێشکەوتن هەڵدەگیرێت و لە کۆتاییدا **بڕوانامە** بە ناوی خۆت وەردەگریت 🏆
- **هەڵەی کوردی**: «`نەزانراو` پێناسە نەکراوە. ئایا ناوەکەت ڕاست نووسیوە؟»
- **ئاسوودە**: بازنەی بێکۆتایی دەوەستێنرێت (Web Worker + کاتی سنووردار)
- **بێ پێویستی بە هیچ پاکێج**: یەک فایلی JavaScript (`docs/kodker.js`)
- **CLI**: `kodker file.kd`

## 🎨 کێشان (Canvas)

لە Playground دا هەر کۆدێک شتێک بکێشێت، تابی **🎨 وێنە** خۆکارانە دەکرێتەوە (لەگەڵ دوگمەی «دووبارە» و «PNG»). `(٠، ٠)` سووچی سەرەوەی چەپە.

```
قەبارە(٥٠٠، ٣٣٠)           // ئاڵای کوردستان
ڕەنگبکە("سوور")
لاکێش(٠، ٠، ٥٠٠، ١١٠)
```
> هەر فەرمانێک لە دێڕێکی جیا بنووسە، یان بە `؛` جیایان بکەرەوە.

| فەرمان | کار |
|---|---|
| `قەبارە(پان، بەرز)` · `پاشبنەمابکە(ڕەنگ)` · `پاککەرەوە()` | کانڤاس |
| `ڕەنگبکە(ڕەنگ)` · `هێڵڕەنگبکە(ڕەنگ)` · `ئەستووریبکە(n)` | ستایل |
| `بازنە(x، y، r)` · `لاکێش(x، y، پان، بەرز)` · `هێڵ(x١، y١، x٢، y٢)` | شێوە (پڕ) |
| `بازنەهێڵ` · `لاکێشەهێڵ` · `سێگۆشەهێڵ` · `ئەستێرەهێڵ` | شێوە (تەنها هێڵ) |
| `سێگۆشە(...٦ ژمارە)` · `ئەستێرە(x، y، r، n)` · `خۆر(x، y، r)` · `نووسین(دەق، x، y)` | شێوەی تر |
| `پێشەوە(n)` · `دواوە(n)` · `بۆچەپ(d)` · `بۆڕاست(d)` · `بچۆبۆ(x، y)` · `قەڵەمبەرز()` · `قەڵەمدابنێ()` | قەڵەمی کیسە |
| `فریم()` · `خێرایی(fps)` | ئەنیمەیشن |
| `ڕەنگی(r، g، b)` · `پەلکەزێڕینە(پلە، ئەلفا)` · `سینۆس` · `کۆسینۆس` | ڕەنگ و بیرکاری |

**ڕەنگی کوردی:** `"سوور"` `"سەوز"` `"شین"` `"زەرد"` `"نارنجی"` `"وەنەوشەیی"` `"پەمەیی"` `"ڕەش"` `"سپی"` `"خۆڵەمێشی"` `"قاوەیی"` `"ئاسمانی"` (یان هەر ڕەنگێکی CSS وەک `"#ff8420"`).

فەرمانەکان تۆمار دەکرێن و پاشان لێدەدرێنەوە، بۆیە کێشانیش لە Web Worker دا ئاسوودەیە (سنوور: ٢٠٠ هەزار فەرمان، ٣٠٠٠ فریم). بەرنامە لە ماوەی هەڵەدا ئەوەی کێشرابوو نیشان دەدات.

## 🎮 یاری
بە `یاریبکە` دەتوانیت یاریی زیندوو دروست بکەیت: کۆدی ناوەوە ٦٠ جار لە چرکەیەکدا جێبەجێ دەبێت.

```
گۆڕاو x = ١٠٠
یاریبکە(() => {
  پاشبنەمابکە("ڕەش")
  ئەگەر کلیل("ڕاست") { x += ٥ }
  ئەگەر کلیل("چەپ") { x -= ٥ }
  x = سنوور(x، ٠، ٣٦٠)
  ڕەنگبکە("زەرد")
  بازنە(x، ١٠٠، ٢٠)
})
```

| فەنکشن | کار |
|---|---|
| `یاریبکە(کار)` | بازنەی یاری (٦٠ فریم لە چرکەیەکدا، یان بە `خێرایی(n)`) |
| `کلیل("چەپ")` | ڕاستە ئەگەر کلیلەکە دابگیرابێت: `چەپ` `ڕاست` `سەرەوە` `خوارەوە` `بۆشایی` `ئینتەر` `ئێسکەیپ` `شیفت` و پیتەکان (`"a"`، `"w"` ...) |
| `ماوسX()` · `ماوسY()` | شوێنی ماوس/پەنجە لەسەر وێنەکە |
| `ماوسگیراوە()` · `کلیککراوە()` | ماوس دابگیراوە؟ · تەنها لە فریمی کلیک |
| `دووری(x١، y١، x٢، y٢)` · `سنوور(x، کەم، زۆر)` | یارمەتیدەرەکانی پێکدادان و سنووردارکردن |
| `ئێستا()` | `{ سەعات، خولەک، چرکە, میلیچرکە }` بۆ کاتژمێر |

نموونەی تەواو لە `examples/`: **بگرە!**، **ئێکس-ئۆ**، **تێتریس**، **تانکەکان**، **پازڵی خشتە**، **باڵندە توڕەکان**، **پۆنگی دوو کەس**، **پاراستنی قەڵا**، **ماسی گەورە**، **ڕیتم**، **داگیرکەرانی ئاسمان**، **گۆڵف**، **تاوەری هانۆی**، **بووڵەکان**، **سندووقەکان**، **مین‌ڕووت**، **تیرهاوێژی**، **خۆرەکێش**، **چوار بە دووی یەک**، **بۆقە**، **ئەستێرۆیید**، **٢٠٤٨**، **نیشتنەوە لەسەر مانگ**، **پیچەڵپێچ**، **سایمن**، **ڕێگا**، **ڕاکردن**، **بیرەوەری**، **پەنجەنگار**، **مار**، **فڵاپی**، **بریک‌ئاوت**، کاتژمێر، سیستەمی خۆر، ئاتەشبازی. فێرکارییەکەش بەشێکی تەواوی «🎮 یاری دروست بکە»ی هەیە.

## 💻 بەکارهێنان

### لە وێبگەڕ
بچۆ بۆ **[hamaleo.github.io/kodker](https://hamaleo.github.io/kodker/)** (دوای چالاککردنی GitHub Pages، بڕوانە خوارەوە).

### لە تێرمیناڵ (پێویستی بە Node.js ≥ 18 هەیە)
```bash
git clone https://github.com/HamaLeo/kodker.git
cd kodker
node bin/kodker.js examples/02-fibonacci.kd       # جێبەجێکردن
node bin/kodker.js --js examples/02-fibonacci.kd  # تەنها JavaScript ـەکەی نیشان بدە
```

### وەک کتێبخانە
```js
const Kodker = require('./docs/kodker.js');
Kodker.transpile('چاپ(١ + ٢)');              // ← کۆدی JavaScript دەگەڕێنێتەوە
Kodker.run('چاپ(١ + ٢)', { print: console.log });
```

## English summary
**Kodker** (کۆدکەر, "coder") lets people write programs using Kurdish (Sorani) keywords. It is a small, dependency-free transpiler to JavaScript with a browser playground (`docs/`), a CLI (`bin/kodker.js`), Kurdish error messages, support for Kurdish/Arabic-Indic digits, and infinite-loop protection via Web Workers.
